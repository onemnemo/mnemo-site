Notes, mind maps and flashcards in one app

Mnemo is a free, open source desktop app for notes, mind maps and flashcards. It works offline on Windows, macOS and Linux.

Download Mnemo View on GitHub

Notes

Notes support headings, lists, checklists, quotes, callouts, tables, images, code blocks and two-column layouts. Equations are written in LaTeX, inline or as a block. Notes can link to each other and be sorted into nested folders. Markdown shortcuts work while typing. Ctrl+K searches all notes, cards and maps. Notes export to Markdown, PDF or a .mnemo package.

Equations

LaTeX, inline or as a block.

Columns and callouts

Two-column layouts and callouts.

Code blocks

Syntax highlighting and line numbers.

Mind maps

Tab adds a child node and Enter adds a sibling. Maps can also hold shapes, text labels, frames, images and links between branches. Maps export to PNG, SVG or a Markdown outline.

Flashcards

Card types are basic, basic and reverse, vocabulary and cloze, plus custom types with your own fields and templates. Cards can hold LaTeX and images. Decks sit in nested folders and can be tagged. Anki decks can be imported.

Reviews

Grade each card Again, Hard, Good or Easy.

Decks

Table of cards with filters for due, new, suspended and flagged. Bulk editing.

Review scheduling

Reviews are scheduled with FSRS, the algorithm Anki also uses. Each review is graded Again, Hard, Good or Easy. Daily limits apply to new cards and reviews. Cram and test modes do not change the schedule.

Free

Mnemo is free and has no ads.

Works offline

No internet connection is needed. Your library is stored on your computer.

Open source

The source code is on GitHub under the GPLv3 license.

Questions

Is Mnemo free?

Yes. The desktop app is free and open source. Hosted sync, when it is released, will have free and paid tiers. You can also host your own sync server.

Which devices does Mnemo run on?

Windows 10 and 11, macOS on Apple silicon, and Linux. An Android tablet version is in development. Phone versions are planned after that.

Can I import from Anki, Markdown or Notion?

Mnemo imports Anki decks, and Markdown files or folders. Notion exports are imported with a separate converter. See Importing in the docs.

Does Mnemo include AI features?

No. If AI or MCP integrations are added, they will be optional extensions. Only install extensions from sources you trust.

Who makes Mnemo?

A small team of students. Mnemo has been in development for five years. You can report bugs, translate the app or contribute code on GitHub.
