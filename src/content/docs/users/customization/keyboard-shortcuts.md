Most shortcuts in Mnemo can be changed under **Settings → Keyboard**.

Mnemo uses the standard modifier for your platform: `Ctrl` on Windows and Linux, and `Cmd` on macOS.

## Rebinding shortcuts

Choose **Edit shortcut**, then press the key combination you want to use.

Use **Restore default** to reset a single shortcut, or reset all shortcuts from the Keyboard settings page.

Mnemo will warn you if a shortcut conflicts with another action in the same area.

## Editor shortcuts

Some editor shortcuts, such as `Ctrl+B` for bold, are currently fixed and cannot be rebound.
