Every shortcut in Mnemo is rebindable. The manager lives in Settings under General, behind the Keyboard shortcuts row, and lists every action the app registers, grouped by area.

Throughout Mnemo, shortcuts are written with the platform's own keys: Ctrl on Windows and Linux is Cmd on macOS.

## Rebinding

Each action offers **Edit shortcut**: press the keys you want and the new chord is captured directly (Escape cancels). **Restore default** puts a single action back; a confirm-guarded reset restores everything at once.

If two enabled actions in the same area end up sharing a chord, the manager highlights the conflict in red rather than guessing which one you meant. Resolve it by changing either side.

## Where the defaults are documented

Rather than one giant table that drifts out of date, each area's defaults live with its docs:

- Editor formatting chords in [Formatting text](../modules/notes/formatting-text.md).
- Study session keys in [Study modes](../modules/flashcards/study-modes.md).
- Notes workspace keys (new note, search, find) in [Organizing your notes](../modules/notes/organizing-notes.md).

The manager itself is always the live source of truth, since it shows your overrides too.
