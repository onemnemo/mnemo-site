Mnemo speaks five languages: English, Deutsch, Español, Norsk, and 日本語. You pick one during first-run onboarding, and can change it any time in Settings under General; switching applies immediately.

## When a translation is missing

Mnemo is developed in English, so new features occasionally ship before every translation catches up. When a string is untranslated, the app shows the English text rather than a placeholder or an error code, and the gap closes as translations land.

## Help translate

Translations live as plain JSON files in the [app repository](https://github.com/onemnemo/mnemo), which makes fixing a clumsy phrase in your language one of the friendliest first contributions there is.
