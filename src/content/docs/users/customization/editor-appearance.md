Editor settings are available under **Settings → Editor**.

## Width and text size

**Editor Width** controls the width of the writing area. Choose from:

* Super Compact
* Compact
* Wide
* Super Wide

The default is **Wide**.

You can also change the width directly from a note's menu under **Editor Width**.

**Base Font Size** ranges from 12px to 18px and defaults to 16px. It currently applies to card content in review and test.

**Auto-save** is enabled by default. See [How saving works](../modules/notes/how-saving-works.md) for more about saving and manual save mode.

## Math

Math is rendered automatically in notes, flashcards, and mindmaps.

Inline equations follow the surrounding text size. Invalid LaTeX is shown as written so you can correct it.

For writing equations, see:

* [Formatting text](../modules/notes/formatting-text.md)
* [Writing cards](../modules/flashcards/writing-cards.md)

## Spelling and fonts

Spelling settings have their own page under **Settings → Spelling**. See [Spelling](../modules/notes/spelling.md) for languages, spell checking, and your personal word list.

Mnemo currently uses its built-in fonts for interface text, code, and math.
