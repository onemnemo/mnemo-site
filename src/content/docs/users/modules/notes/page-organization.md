A note can have a cover banner, a page icon, and tags above its title. All three are optional.

## Covers and icons

**Add cover** offers preset gradients, and **Upload image** takes a picture of your own: PNG, JPEG, GIF, WebP, or BMP, up to 20 MB.

The page icon is an emoji shown above the title. The picker searches by name and keyword.

## Tags

Tags are labels shown as chips under the title. Hover the row, press **Add tag**, type a label, and press Enter. Each tag gets a color from its label, so the same tag looks the same in every note.

Tags in notes are labels only. Nothing in Mnemo searches or filters notes by tag yet; the sidebar search matches titles. Tags do print on a [PDF export](./pdf-export.md) and travel with the note through import and export.
