A note can carry a cover banner, a page icon, and a row of tags above its title. All three are optional, and they exist to make a note recognizable at a glance.

## Covers and icons

**Add cover** opens on a set of preset gradients, and **Upload image** takes a picture of your own: PNG, JPEG, GIF, WebP, and BMP work, up to 20 MB, the same limits an image block accepts.

The page icon is a single emoji shown large above the title. Its picker searches names, keywords, and Mnemo's own aliases, and its categories reorder against the note's name, so a note called "Pharmacology" opens with medicine near the top.

## Tags

Tags are freeform labels shown as chips under the title. Hover the row, press **Add tag**, type a label, and press Enter. A chip's colour is derived from the label, so the same tag reads the same colour in every note.

## What tags cannot do yet

Nothing in Mnemo searches or filters by tags: the sidebar search (`Ctrl+P`) matches note titles, and the command palette's tag scope covers flashcard decks, not notes. Treat them as annotation you read, not as a way to find a note again.

They are not inert, though. Tags print on a [PDF export](./pdf-export.md) as tinted pills, and they travel with a note through import and export.
