**Browse cards**, at the top of the library, lists every card in your collection in one table. It is the only view that searches across decks.

## Search

The search box matches front text, back text, and tags, not deck names. Every word you type must match, and each word matches as a prefix, so `cell mem` finds a card about the cell membrane.

## Filters

Filters combine. **Clear** removes all filters and empties the search box.

| Filter    | Where                 | Options                                                      |
| --------- | --------------------- | ------------------------------------------------------------ |
| State     | Chips above the table | All, Due, New, Learning, Suspended, Flagged                  |
| Deck      | **Filter** menu       | One deck, by its full folder path                            |
| Tag       | **Filter** menu       | Any tag in the collection                                    |
| Card type | **Filter** menu       | Any card type                                                |
| Forgotten | **Filter** menu       | Forgotten at least once, Forgotten 3+ times, Never forgotten |

## Editing cards

Right-click a row to peek, edit, flag, suspend, move to another deck, or delete. Select several rows for the same actions in bulk: **Move to**, **Tag**, **Suspend**, **Flag**, and **Delete**.

**Delete** moves cards to the trash without asking first. A toast offers **Undo**. Deleted cards stay in the trash for 30 days.
