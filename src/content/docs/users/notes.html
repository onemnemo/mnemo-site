Blocks

Every line in a note is a block. Type / at the start of a line and keep typing to filter the menu. The English block names work in every language.

Text and headings Paragraphs and four levels of headings. Headings also show up in the note's index, so you can jump around long notes.
Lists and to dos Bullet lists, numbered lists and checklists.
Quote, callout and warning Asides that stand out from the text. Click a callout's icon to change its emoji.
Code A code block with highlighting for the language you pick.
Two columns Two stacks of blocks side by side, with a divider you can drag.
Image and table Pictures with an optional caption, and tables with rows and columns.
Equation A block of LaTeX maths on its own line.
Page A note inside a note, shown as a link with its title.

Markdown as you type

At the start of a line, type a marker and a space: # to #### for headings, - for a list, 1. for a numbered list, [] for a to do, > for a quote, three backticks for code and --- for a divider.

Formatting

Select text to bring up the formatting bar, or use the keys below. On a Mac, use Cmd for Ctrl.

Ctrl B Ctrl I Ctrl U Bold, italic, underline
Ctrl Shift S Strikethrough
Ctrl Shift H Highlight
Ctrl E Inline code
Ctrl Shift L Add or edit a link
Ctrl Shift E Insert an equation in the line

For maths, write LaTeX between dollar signs, like $E = mc^2$. If the LaTeX has a mistake, it stays as you typed it so you can fix it.

Staying organised

  • Drag notes into folders in the sidebar, and drag folders into each other to nest them.
  • Star the notes you open most. They sit in their own section at the top.
  • Ctrl P finds a note by title, and Ctrl F finds and replaces inside the one you're reading.
  • Hold Alt and click a note to open it in the side peek, so you can read one note while writing another.

A good rule of thumb: one note per topic. When a section outgrows the page, move it into a note of its own.

Saving

Notes save as you type, and Ctrl S saves right away. If a save fails, the corner of the note says so and Mnemo keeps retrying. Prefer saving by hand? Turn off Auto save under Settings, then Editor. Closing a note always saves it.

Exporting

Pick Export from a note's menu. Markdown gives you plain text any editor can open, though images and column layouts don't come along. A .mnemo package keeps everything exactly as it is. Export as PDF lets you pick the paper size, margins, text size and page numbers.

Bringing notes in is covered in Importing.
