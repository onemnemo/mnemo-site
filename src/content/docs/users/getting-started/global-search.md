Press `Ctrl+K` (`Cmd+K` on macOS) to open the command palette from anywhere in Mnemo.

You can also open it from **Search** in the topbar.

## What it searches

The command palette can find:

* note titles
* deck names
* pages in the sidebar
* actions such as **Toggle theme** and **Toggle sidebar**

It does not search note contents or card fronts and backs.

For card content, use **Browse cards** in Flashcards.

## Filters

With an empty search, the palette shows recent items, navigation shortcuts, and available actions.

Use:

* `>` to show only actions
* `#` to search deck tags

## Keyboard controls

Use the arrow keys to move through results and `Enter` to open the selected item.

Press `Esc` to clear the current filter or close the palette.

If Soma is enabled, searches with no matching result can also be sent to Soma.
