Mnemo is a desktop app. There is no account to create and no server to connect to: you download it, open it, and start learning.

## Download the right build

Grab the latest release from the [download page](https://mnemo.one/download). Pick the build for your platform:

| Platform | File             | Notes                                              |
| -------- | ---------------- | -------------------------------------------------- |
| Windows  | `.exe` installer | Windows 10 or newer                                |
| macOS    | `.pkg`           | Apple Silicon and Intel                            |
| Linux    | `.AppImage`      | No installation needed; make it executable and run |

Every release is also published on [GitHub Releases](https://github.com/onemnemo/mnemo/releases/latest) with checksums if you want to verify your download.

## Install and first launch

Run the installer (or open the AppImage) and launch Mnemo. On first launch the app creates a local data folder for your decks, notes, and maps. That folder is the single source of truth: nothing leaves your machine unless you export it yourself.

## Where your data lives

Your library is stored in your user data directory. Back that folder up and you have backed up everything. Copy it to a new machine and Mnemo picks it up on the next launch.
