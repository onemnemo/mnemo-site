Start a map

Open Mind maps, choose New, then Map. Pick a name and a starting template. Press N and click to place your first node. Name it after the subject and keep it broad, since everything else grows from there.

Build it from the keyboard

Tab Add a child
Enter Add a sibling
Shift Tab Move a node out from under its parent
F2 Edit the label, or double click the node
Ctrl D Duplicate the selection
Delete Remove the selection
Ctrl 0 Fit the whole map on screen

Dragging a node moves its whole branch.

Tools

The dock at the bottom of the canvas covers what you place by hand. Each tool goes back to Select after one use.

V Select Select, drag and resize
N Node Place a node and start typing
S Shape Place a shape
T Text Place a loose label
C Connect Draw a link between two nodes
F Frame Draw a frame around a group
I Image Place a picture

To link two branches, press C and drag from one node to the other. Drag the same link again to remove it. Hold Q for a radial menu with the most common actions.

When a branch gets crowded, move it into a map of its own.

Exporting

Export on the map toolbar saves a PNG or SVG picture, or a Markdown outline of the whole map. To move maps between computers, use Transfer in the library to export or import .mnemo packages.
