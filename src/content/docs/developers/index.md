Mnemo is free software under the Apache-2.0 license, developed in the open at [github.com/onemnemo/mnemo](https://github.com/onemnemo/mnemo). These docs are for anyone who wants to build it, poke at its internals, or contribute.

Start with [Building from source](./getting-started/building-from-source.md), skim the [Architecture](./architecture/index.md) pages to learn where code belongs, and read [How to contribute](./contributing/how-to-contribute.md) before opening your first pull request.
