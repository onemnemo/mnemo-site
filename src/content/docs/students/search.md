---
title: Search
description: Finding notes, flashcards, mind maps, and settings from anywhere in the app.
category: Workspace
order: 30
---

Press `Ctrl+K` or click the search field in the top bar to open global search. It looks across everything in your workspace:

| Group | What is matched |
| :--- | :--- |
| Navigate to | Pages of the app itself |
| Notes | Titles and full note content |
| Decks | Deck names, descriptions, and tags |
| Flashcards | The front, back, and tags of every card |
| Mindmaps | Map titles and all node text |
| Settings | Individual settings entries |

Selecting a result jumps straight to it: a note opens in the editor, a flashcard opens inside its deck, a setting opens its settings page.

Search is fuzzy. Words that are close to a match still count, so a small typo usually does not hide a result. Title matches rank above content matches.

When several flashcards share the same topic words, search groups them into a topic cluster so one query can surface a whole theme.

Some pages have their own local search as well, such as the flashcard library and the mind map list. These filter only the list you are looking at.
