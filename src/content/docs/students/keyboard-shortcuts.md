`Ctrl` means `Cmd` on macOS.

## Global

| Action | Shortcut |
| :--- | :--- |
| Global search | `Ctrl+K` |
| Quick actions | `Alt+Shift+Q` |

## Note editor

| Action | Shortcut |
| :--- | :--- |
| Bold | `Ctrl+B` |
| Italic | `Ctrl+I` |
| Underline | `Ctrl+U` |
| Strikethrough | `Ctrl+Shift+S` |
| Highlight | `Ctrl+Shift+H` |
| Link | `Ctrl+Shift+L` |
| Subscript | `Ctrl+,` |
| Superscript | `Ctrl+.` |
| Copy, cut, paste | `Ctrl+C`, `Ctrl+X`, `Ctrl+V` |
| Reset editor view | `Ctrl+0` |

## Mind maps

| Action | Shortcut |
| :--- | :--- |
| Add child node | `Tab` |
| Confirm / edit node | `Enter` |
| Edit edge label | `F2` |
| Delete selection | `Delete` or `Backspace` |
| Clear selection | `Escape` |
| Undo, redo | `Ctrl+Z`, `Ctrl+Y` |
| Copy, paste, duplicate | `Ctrl+C`, `Ctrl+V`, `Ctrl+D` |
| Recenter view | `Ctrl+0` |

## Flashcard editor

| Action | Shortcut |
| :--- | :--- |
| Save card and start a new one | `Ctrl+Enter` |
| Wrap selection in a cloze | `Ctrl+Shift+C` |

## Rebinding

Open **Settings → Hotkeys** to open the keybind manager. Every action above can be rebound or disabled. The manager flags conflicts: two actions in the same scope cannot share a chord, and it warns when a local shortcut shadows a global one. Custom binds are saved locally and survive updates.
