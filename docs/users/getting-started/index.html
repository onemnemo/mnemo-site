Getting started

Install Mnemo, then make your first note, mind map and deck.

Install Mnemo

Grab the build for your computer from the download page. There's no account to make, and your library stays on your own machine.

Windows

Run the .exe installer. It's made for Windows 10 and 11. The build isn't signed yet, so Windows may show a SmartScreen warning the first time. Click More info, then Run anyway.

Mnemo needs the Microsoft Edge WebView2 runtime. Almost every Windows 10 and 11 machine has it already. If the app won't start, install WebView2 and try again.

macOS

Open the .pkg installer. It runs on Apple silicon Macs, M1 and newer. There's no build for Intel Macs.

Linux

Use the AppImage for most distros, or the portable .tar.gz if you'd rather unpack it yourself. The build targets Ubuntu 22.04 and newer. Give the AppImage permission to run from its file properties, or with chmod +x on the file.

It also needs a few system libraries. On Ubuntu 24.04 this installs them all:

sudo apt install libfuse2t64 libwebkit2gtk-4.1-0 libjavascriptcoregtk-4.1-0 libgtk-3-0t64 libnotify4

Package names differ a little on other distros.

First launch

A short setup asks for your name and language, and then you're in. Mnemo checks for updates on its own and asks before installing one.

Mnemo is still young and moving fast. Keep a backup of your library, especially before you update.

Your first note

Press Ctrl N, give it a title and start typing. Notes save on their own as you write. Type / at the start of a line to pick a block, like a heading, a list or a table. Or just type Markdown: # and a space makes a heading, - makes a list.

There's more in Notes.

Your first mind map

Open Mind maps, choose New, then Map. Press N and click to place your first node, and name it after the subject. With a node selected, Tab adds a child and Enter adds a sibling, so you can build the whole map without touching the mouse.

There's more in Mind maps.

Your first deck

Open Flashcards, make a new deck and add a few cards from something you're studying right now. Keep each card to one question. Ctrl Enter saves a card and keeps the editor open for the next one.

Then press Study. Try to recall the answer, reveal it and grade how it went. Mnemo uses that grade to decide when you'll see the card again. When the session ends, you're done for today. Missed a day? No problem, due cards simply wait for you.

There's more in Flashcards.

Shortcuts worth learning

These few save the most time. On a Mac, use Cmd wherever you see Ctrl.

Ctrl KOpen the command palette to jump to any note, deck or action
Ctrl NNew note
/Pick a block type in a note
Ctrl PFind a note by title
Alt EnterOpen the focused note in the side peek, next to what you're working on
Tab and EnterAdd a child or sibling node in a mind map
Ctrl EnterSave a card and start the next
SpaceReveal the answer in a review, press again for Good
1 to 4Grade Again, Hard, Good or Easy

In the command palette, start with > to see only actions, or # to search deck tags. Most shortcuts can be changed under Settings, then Keyboard.
