Local development

How to clone the repository and run a development build.

Mnemo is one desktop app built from two halves: a React frontend in mnemo-web, and a .NET backend in Mnemo.Host that opens the window, runs the local API and serves the frontend.

What you need

  • The .NET 10 SDK.
  • Node.js 24 with npm.
  • Git, and on Linux or macOS also jq.

Clone and restore

git clone https://github.com/onemnemo/mnemo.git
cd mnemo/mnemo-web
npm install
cd ..

Then fetch the bundled Typst binary. It's about 52 MB per platform, so it isn't committed. On Windows run ./scripts/restore-typst.ps1, elsewhere ./scripts/restore-typst.sh. The build works without it, but PDF export from notes quietly stops working.

Run a development build

On Windows, dev.bat does everything for you. Everywhere else, start the host first:

dotnet run --project Mnemo.Host -- --dev

Then the web UI in a second terminal:

cd mnemo-web
npm run dev

The order matters. In dev mode the host listens on 127.0.0.1:47210 and writes mnemo-web/.dev/api.json with the port and a fresh token. The Vite proxy reads that file and adds the token to every API call. Start Vite first and your API calls come back unauthorised until you restart it.

Keep your real library safe

A development build uses the same data folder as an installed Mnemo. Point MNEMO_DATA_DIR at a scratch folder to keep them apart:

MNEMO_DATA_DIR=/tmp/mnemo-dev dotnet run --project Mnemo.Host -- --dev

Run the tests

Every push to main and every pull request runs the same checks you can run locally. Run the half you touched before each push, and both before a pull request.

dotnet test MnemoApp.slnBoth xUnit projects, for Infrastructure and the Host
npm run testThe Vitest suite, run from mnemo-web
npm run lintoxlint
npx tsc -bTypechecking

Test files sit next to the code they cover. Files that need a DOM opt in with a // @vitest-environment jsdom line at the top.

Stuck on a build error? Search the existing issues first. If it looks new, open one with your OS, tool versions and the full error.

Something unclear or missing? Tell us on GitHub.
