Roadmap

Current version: 0.8.2. The releases below are listed in planned order. This page is updated when plans change.

0.9

Redesign

A redesign of the interface with new navigation. Notes, flashcards and mind maps share one set of tabs.

  • A new interface throughout the app
  • New navigation
  • Shared tabs for notes, flashcards and mind maps
0.10

Performance

A release focused on speed.

  • Faster startup
  • Faster switching between tabs
  • Better performance in large documents
  • Lower memory use
0.11

New features

Some of these may be spread over several releases.

  • Sync and extensions
  • Databases, similar to those in Notion
  • New editor blocks
  • Layouts with three or four columns
1.0

Stable release

The first stable release. Hosted sync may be offered as an optional paid service. The app stays free and open source.
